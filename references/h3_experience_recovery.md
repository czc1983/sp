## 二、白膜提示词写法（六区块规范 + 血泪教训）

结构：**参考分工 → 风格合约 → 时间轴（[0s-1s]/[1s-2.5s]/[2.5s-4s]/[4s-5s]）→ 镜头 → 音频 → 负面清单**。

决定性教训：
1. **镜子/反射构图必须讲透**：「左侧是椭圆镜，镜中是倒影；右侧才是本体；倒影与本体是同一对人，人物总数为 2 不是 4」。不讲透模型就把镜子删了。
2. **颜色绑定**：倒影与各自本体严格同色（否则颜色漂移）。
3. **背景只换材质不删结构**：写「统一纯白色」会被理解成白色虚空；要写「空间结构完整保留，仅材质替换为哑光浅色」。
4. **音频区块禁止引述画面文字**（字幕会被当成台词重新配音，中文台词事故就是这么来的）。音频区块只写「台词与参考音频完全一致」。
5. 口型机制是双重引导：原片音频作参考输入 + 提示词写死对白内容/情绪/节奏拍点；H3 声画同次生成。

## 三、自动反推管线（原视频 → 六区块提示词）

四步设计：切片抽帧（现有）→ ASR 拿台词时间码（dubvideo 现有，**必须走音频不能看字幕**）→ VLM 结构化反推 → 模板组装提交（风格合约/负面清单固定模板，只反推时间轴/镜头/音频）。

模型选型实测（同一条镜子原片）：

| 方案 | 结论 |
|---|---|
| 本地 Qwen2.5-VL-7B（已装服务器 `/root/Qwen-VL/models/`） | 不够格：人数数错（把倒影当第三人）、时间轴编故事、漏字幕、镜头判断错 |
| 百炼 qwen-vl-max | 质变：人数对、字幕读得出、不硬编；但漏手部动作、镜中身份偶尔互换 |
| 百炼 qwen3-vl-235b-thinking | 最强，瑕疵全修；但 think 模式太慢太贵 |
| **最终定稿：kimi-k2.5 反推 + 235B 复核（混合管线）** | 16 次调用 231 秒/条，约 **0.42 元/条**（北京区免费额度内为 0），质量超过纯 235B 全程——跨模型复核能抓到单模型自查抓不到的错误 |

- 工程要点：逐帧问动作而非自由编故事；提示词先打「倒影不是独立人物」预防针；名册（roster）机制按段缓存；235B 复核输出要自动剥离档案回显。
- 脚本与产物：`E:\sp\h3_debug\bailian_reverse.py`（带缓存可续跑）、`prompt_v4_kimi-k2_5_hybrid.txt`、各 `cost_report_*.txt`。
- 已知漏检：seg_016 实际有 3 个角色（地上喊叫的是第三人），反推只检出 2 个——多人场景名册需要人工抽查兜底。
